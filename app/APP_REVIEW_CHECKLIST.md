# Проверка перед отправкой в App Store

## Сборка и содержимое

- [ ] Удалить из **релизной сборки** тестовые `Resources/monono.gif`, `Resources/monono_widget_exact.gif`, `Resources/test.gif`, `Resources/ci_frames.gif` и меню тестовых анимаций. Проверить содержимое архива `.ipa`, а не только экран приложения. Тестовые ресурсы в отдельном test target могут остаться, если они не попадают в приложение.
- [ ] Убрать или закрыть от обычного пользователя dev-панель, CI-сценарии и диагностические функции, которые не относятся к релизу; проверить первый запуск без заранее импортированных файлов.
- [ ] Проверить импорт GIF, видео и Live Photo, редактирование, сохранение, выбор анимации в виджете, удаление проекта, восстановление после перезапуска и отсутствие пустого/сломанного виджета. Показать в приложении понятный путь добавления виджета на Home Screen. Для [§4.2 Minimum Functionality](https://developer.apple.com/app-store/review/guidelines/#minimum-functionality) ценность приложения должна быть видна без тестового контента: пользователь превращает собственный файл в настраиваемый анимированный виджет.
- [ ] Проверить на iOS 18 и актуальной iOS, на реальном iPhone; архивировать с поддерживаемым SDK. Сейчас App Store Connect требует Xcode 26+ для iOS-сборок; с **апреля 2027** Apple требует **iOS/iPadOS 27 SDK или новее** ([Upload builds](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds), [Submitting](https://developer.apple.com/app-store/submitting/)).

## Публичные API и приватность

- [ ] Проверить финальный архив на отсутствие приватных API, нестандартных entitlement и скрытых зависимостей. Анимация должна оставаться на публичных `Text(.timer)` и шрифтах-масках; сверить [§2.5.1 Software Requirements](https://developer.apple.com/app-store/review/guidelines/#software-requirements). Не обещать гарантированную частоту кадров или одинаковое поведение на всех версиях iOS.
- [ ] Повторить аудит Required Reason API после последних изменений кода и проверить Privacy Report/валидацию архива. Текущие находки: `App/WidgetLabApp.swift:255–257` — `contentModificationDateKey` для локального `settings.json`, `C617.1`; `App/DevPanelView.swift:158–159` — `.systemFreeSize`, показывается на экране диагностики, `85F4.1`. В исходниках расширения, включая `Shared/`, прямых обращений к `UserDefaults`, `systemUptime` и другим категориям не найдено. `fileSizeKey` используется для контроля размера импорта, но отсутствует в перечне Apple Required Reason API. Сверять с [перечнем API и reason-кодов Apple](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype) и [TN3183](https://developer.apple.com/documentation/technotes/tn3183-adding-required-reason-api-entries-to-your-privacy-manifest).
- [ ] Проверить, что оба `PrivacyInfo.xcprivacy` включены в соответствующие bundle и отражают финальный код. Для App Store Connect выбрать **Data Not Collected**, если в релизе действительно нет сбора данных приложением или SDK. Импортированные файлы и проекты остаются локально в контейнере/App Group; перепроверить это после любых новых SDK, сети или аналитики. [App privacy details](https://developer.apple.com/app-store/app-privacy-details/), [§5.1 Privacy](https://developer.apple.com/app-store/review/guidelines/#privacy).
- [ ] Проверить доступ к Фото: обычный `PhotosPicker` работает с выбранным пользователем элементом без общего доступа к библиотеке; путь Live Photo дополнительно использует `PHAssetResource`. В `Info.plist` добавлено описание `NSPhotoLibraryUsageDescription` для возможного системного запроса PhotoKit. Проверить Live Photo на устройстве с локальным и iCloud-объектом. `PHAssetResourceRequestOptions.isNetworkAccessAllowed = true` может позволить системной Photos скачать выбранный объект из iCloud; учитывать это при проверке формулировок о работе без сети. [PhotoKit privacy](https://developer.apple.com/documentation/photokit/delivering-an-enhanced-privacy-experience-in-your-photos-app).

## Права и страница магазина

- [ ] Использовать в иконке, скриншотах и примерах только свои изображения или материалы с подтверждёнными правами. Не показывать чужих персонажей, логотипы, кадры фильмов и бренды. Проверить лицензию и атрибуцию WidgetAnimation в экране Licenses. [§5.2 Intellectual Property](https://developer.apple.com/app-store/review/guidelines/#intellectual-property).
- [ ] Сверить название, subtitle, keywords, описание, категорию, скриншоты и обещания с фактической релизной сборкой; не показывать Pro как доступную покупку до её реализации. Для ревью добавить конкретные шаги: импорт собственного GIF/видео → сохранение → добавление виджета → выбор проекта. [§2.3 Accurate Metadata](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata).
- [ ] Подготовить 1–10 настоящих скриншотов приложения на iPhone, без прозрачности. Для 6.9″ Apple принимает, например, **1320×2868**, **1290×2796** или **1260×2736** (portrait). Если набор 6.9″ отсутствует, потребуется набор 6.5″ (**1284×2778** или **1242×2688**); проверить актуальные размеры перед загрузкой. [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications), [Upload screenshots](https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots).
- [ ] Заполнить анкету возрастного рейтинга согласно фактическим возможностям приложения и проверить итоговый рейтинг. Пользовательский импорт сам по себе не означает встроенный взрослый контент; не заявлять рейтинг наугад. [Set an app age rating](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating).
- [ ] Ответить на вопросы export compliance по фактическому использованию криптографии. В `Info.plist` установлено `ITSAppUsesNonExemptEncryption = NO`; перед отправкой сверить, что в релизе не появилось неосвобождённое шифрование. Использование `CryptoKit` для SHA-256 хешей файлов отдельно проверить в анкете, не смешивая хеширование с шифрованием. [Overview of export compliance](https://developer.apple.com/help/app-store-connect/manage-app-information/overview-of-export-compliance).
